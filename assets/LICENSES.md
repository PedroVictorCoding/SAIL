# UI asset provenance

SAIL's current web icon sprite (`source/icons/sail-icons.svg`) and procedural
orb renderer are original project assets, authored for SAIL and distributed
under the repository's MIT OR Apache-2.0 license. No pixels, icons, wallpapers,
or other artwork are extracted from the visual concept reference. The home
background and orb are rendered from CSS and Canvas2D; no remote asset service
is used. User-selected images remain runtime data and are not stored here.
