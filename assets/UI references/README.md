# Retired — UI reference images live in `docs/design/references/ambient-glass/`

This folder previously listed seven expected reference images with different
filenames and checksums. None were ever committed, and the list conflicted with the
eight-image set that `DESIGN.md` and `docs/design/AMBIENT_GLASS_REFERENCES.md` use.

There is now **one** reference folder:
[`docs/design/references/ambient-glass/`](../../docs/design/references/ambient-glass/README.md).
Add owner-supplied reference images there, under the names listed in
[`docs/design/AMBIENT_GLASS_REFERENCES.md`](../../docs/design/AMBIENT_GLASS_REFERENCES.md).
Do not add images to this folder, and never ship reference images in an application bundle.
