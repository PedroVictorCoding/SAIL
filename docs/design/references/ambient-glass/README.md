# Ambient Glass UI References

This directory is the single home for the eight owner-supplied visual reference images for SAIL's ambient-glass, living-light, and motion system. Six are committed; **`02` and `03` are missing** until the owner adds them under exactly these names. These images are design references only: do not copy, bundle or serve them.

1. `01-day-phase-timeline.png` — Four tall black phone screens, chromatic gradient light at bottom, schedule timeline.
2. `02-luminous-feature-panels.png` — Four sparse black cards with bright bottom glow and minimal text.
3. `03-progress-project-cards.png` — Dark projects with small tint, progress bars, remaining-time chips.
4. `04-device-status-capsules.png` — Compact horizontal light-filled hardware status strips.
5. `05-dotted-measurement-tiles.png` — Black dotted measurement UI, colorful panels, circular indicators.
6. `06-gradient-alarm-analytics.png` — Light mint/green gradient alarm, glassy dark analytics cards.
7. `07-saturated-blue-analytics-glow.png` — Deep blue analytical panel with soft bloom, large center metric.
8. `08-immersive-gradient-onboarding.png` — Rich blue/black gradient mobile intro and offer screen.
